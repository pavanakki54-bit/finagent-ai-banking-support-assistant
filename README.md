# FinAgent AI - Agentic Banking Support Assistant

Production-style Generative AI application demonstrating Agentic AI workflows for financial services.

## Architecture

React UI
→ FastAPI Backend
→ LangGraph Agent
→ RAG Pipeline
→ Vector Search
→ LLM Response
→ Verification
→ Human Handoff

## Features

- Multi-agent orchestration
- Retrieval Augmented Generation
- FAISS vector search
- LLM tool calling
- Banking workflow simulation
- Guardrails
- Human escalation

## Tech Stack

Python  
FastAPI  
React  
LangChain  
LangGraph  
FAISS  
Docker  
AWS Architecture Patterns

## Workflow

1. User asks financial question
2. Intent detection
3. Retrieve banking knowledge
4. Execute tools
5. Generate response
6. Validate output
7. Return answer or escalate
